# 🏠 家庭报销管理系统

家庭内部报销管理工具，解决家庭成员之间"谁买了东西、谁该分摊多少、钱转没转"的记账与结算问题。

---

## 📂 项目结构

```
family-money/
│
├── frontend/                       # 前端静态文件
│   └── index.html                  # 主应用（SPA，含登录+全部功能页面）
│
├── backend/                        # 后端服务
│   ├── app.py                      # Flask 服务入口（全部API在此实现）
│   ├── account-manager.html        # 后端账号管理+账单管理页面（管理员专用）
│   ├── requirements.txt            # Python 依赖清单
│   ├── settings.json               # 管理员配置（自动生成）
│   ├── users.json                  # 用户数据（自动生成）
│   ├── bills.json                  # 账单数据（自动生成）
│   ├── claims.json                 # 认领数据（自动生成）
│   ├── backups/                    # 数据备份目录（自动生成）
│   ├── server.log                  # 服务运行日志（自动生成）
│   ├── server-console.html         # 服务控制台页面
│   └── .server.pid                 # 服务进程ID记录（自动生成）
│
├── docs/                           # 项目文档
│   ├── 接口文档.txt                # 接口规范文档
│   └── index快速导览.txt           # 前端代码行号导航
│
├── 快捷工具/                       # 快捷启动工具
│   ├── start.bat                   # 启动后端服务（带控制台窗口）
│   ├── close.bat                   # 停止后端服务
│   ├── start_backend.vbs           # 静默启动脚本（无窗口）
│   ├── start_with_venv.bat         # 自动激活虚拟环境启动
│   ├── 服务控制台.url              # 服务控制台快捷方式
│   ├── 首页 - 家庭报销管家.url     # 首页快捷方式
│   └── 后台管理 - 账号管理.url     # 后台管理快捷方式
│
├── setup.py                        # 项目初始化安装脚本
├── _fix_vbs.py                     # VBS脚本编码修复工具
├── .gitignore                      # Git 忽略规则
├── .venv/                          # Python 虚拟环境
└── README.md                       # 项目说明
```

## 🚀 快速启动

### 方式一：完整运行（推荐）

```bash
# 1. 进入后端目录
cd backend

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动服务（前端页面也由此提供）
python app.py

# 4. 浏览器访问
open http://localhost:3000
```

## 🧩 核心功能

| 页面 | 功能 |
|------|------|
| 📊 **仪表盘** | 总览统计、成员基金池、个人额度速览（含承诺上限自服务 ✏️） |
| 📋 **账单管理** | 创建账单、查看账单列表、认领报销 |
| 📋 **账单管理** | 创建账单、查看账单列表、认领报销 |
| 💰 **查账结算** | 查看应收/应付款、确认转账/收款 |
| 🏆 **激励榜** | 闪电勋章榜、采购达人榜 |
| ⚙️ **后台管理** | 成员管理、额度修改、强制结清（含重置账单、清除排行） |
| 👤 **账号管理** | 添加/编辑/删除成员账号、账单管理（编辑/删除账单及认领） |
| 💾 **备份系统** | 创建备份、恢复备份、删除备份 |
| 💥 **恢复出厂** | 清空所有数据并重新设置管理员 |

## ⚙️ 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | 原生 HTML / CSS / JavaScript（SPA单页应用） |
| 后端 | **Flask** (Python) |
| 数据存储 | JSON 文件（轻量，无需数据库） |
| 认证 | UUID Token |

> **注意**: 当前为轻量实现（Flask + JSON），如需生产部署可参考 `docs/接口文档.txt` 中的 API 规范迁移至 FastAPI + MySQL。
